## LinkedIn project description

Built an end-to-end credit risk prediction system modeled after India's CIBIL credit bureau. The ML pipeline uses a soft-voting ensemble of XGBoost, LightGBM, and Random Forest trained on 10,000 synthetic applicant records with 36 engineered features — including FOIR (Fixed Obligation to Income Ratio), DPD analysis, and CIBIL score interaction terms.

The system achieves a ROC-AUC of 0.80 and is deployed as a full-stack web app with FastAPI (Python), React, JWT authentication, and SQLite. Every prediction includes a risk factor breakdown explaining exactly why an applicant is flagged — mirroring how real Indian banks and NBFCs assess creditworthiness.

Tech: Python · XGBoost · LightGBM · scikit-learn · FastAPI · React · SQLite · Render · Netlify
